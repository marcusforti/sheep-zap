O segredo

Por que parece tão inteligente

Não é um prompt genial. É um sistema simples, com cinco coisas empilhadas. Tire qualquer uma e sobra um chatbot comum.

Um agente só, com uma cópia para cada pedido

Para você, o agente é um só. Por dentro, cada pedido de trabalho abre uma cópia temporária, com a mesma identidade e as mesmas regras. Ela lê arquivo, escreve, roda programa, pesquisa, gera áudio, responde e é encerrada. Com um agente só esperando a própria fila, a minha primeira versão chegou a travar 677 minutos.

Quem lembra é a pasta

Nenhuma cópia lembra de nada. Todas nascem lendo a identidade, os combinados e a memória que estão na pasta do agente, e vão buscar o resto sozinhas. É isso que você copia junto com a skill.

Barato decide, caro trabalha

Um modelo pequeno lê tudo e separa recado de trabalho. Ele também marca o assunto do pedido: dois pedidos sobre a mesma coisa viram uma cópia só, para ninguém refazer o trabalho do outro.

Nunca fica mudo

Em segundos você recebe "Peguei, já tô fazendo", com o que foi entendido. status mostra o que está rodando. Se passar do tempo, ele para e avisa. Se a internet cair, a resposta fica guardada e insiste.

Cada erro vira regra escrita

Essa é a parte que mais pesa. Quando o agente erra, a correção vai para um arquivo que toda cópia nova lê. Nenhuma cópia lembra, mas todas nascem com as lições das anteriores.
